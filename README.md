# Goal
Gauss aims to be a high performance audio editing/processing tool
with a declerative (non-destructive) user interface.

The main goals are creating an efficient backend for audio loading,
audio processing, etc., designing a developer- oriented user interface
with an immediate mode GUI.

# About
This Project is in the earliest stage of development, please don't
view it as an attempt of good software. The scope of this program is
not fully determined yet, so development is infrequent. Don't expect
this to become a full fletched application, at least not by any time
soon. That said, I will welcome Pull Requests in immediate stage of
development.

Expect the documentation and concepts to be changed and revised very
frequently.
